Una propuesta para Argentina

Nivel inicial y primaria sirven como referencias de etapa. Esta hoja usa voseo; el libro común utiliza principalmente instrucciones impersonales para mantener claridad entre las ediciones.

Proyecto local: contá una escena de dos maneras. Inventá dos personajes que miran el mismo lugar. Escribí o dictá una frase de cada uno. Después compará qué información eligió contar cada personaje.

Imprimí solo las páginas que vayan a usar. Revisá la vista previa en A4 o Carta para evitar cortes. La impresión y los materiales físicos no están incluidos.
